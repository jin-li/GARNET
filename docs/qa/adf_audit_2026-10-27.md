# Audit of Cartesian finite-volume ADF development

Audit scope: the working-tree changes to `garnet/adf.py`, `stencil.py`,
`solver.py`, `kernels.py`, and package exports; the four ADF examples; their
three verification modules; and affected adjoint diagnostics. GPU execution
was deferred as requested. Production code was not changed during this audit.
The findings below describe the audited state; the subsequent fixes are
recorded at the end of this report.

## Confirmed findings

### P2: exported adjoint residual diagnostic uses the forward leakage operator

`garnet/quasistatic.py:162` unconditionally calls `ops[g].apply`, including
when `projected_adjoint_residual` requests the adjoint loss. The new Cartesian
ADF eigensolver correctly uses `apply_transpose`, so its result is inconsistent
with this existing exported diagnostic whenever face factors make leakage
nonsymmetric. The diagnostic accepts these solvers without rejecting them.

Reproduction: use the two-cell/two-group material and factor data from
`test_two_group_eigenvalue_against_dense_independent_system`, solve forward and
adjoint with `tol_k=1e-11`, `tol_source=1e-10`, `inner_rtol_floor=1e-12`, then call
the exported projected residuals. Observed values:

- forward k: 1.3127296415740073;
- adjoint k: 1.3127296415721914;
- forward projected residual: 1.97e-12;
- true adjoint relative residual using transposed leakage: 1.34e-12;
- exported projected adjoint residual: **0.58458**.

This can falsely classify a converged ADF adjoint as stale and gives incorrect
adjoint-defect triggers wherever this diagnostic is used. Route the diagnostic
through the same transpose-selection contract as the eigensolver, or reject
ADF solvers explicitly until that integration is supported. Add a regression
using a nonsymmetric ADF eigenpair; the current eigenvector test does not call
the diagnostic.

### P3: factor validation discards complex parts before checking validity

`garnet/adf.py:22` and `garnet/stencil.py:223` cast factors to a real dtype
before applying the finite/positive checks. NumPy inputs containing complex
factors are accepted after a `ComplexWarning`; for example, `1+3j` becomes
unity and runs the no-discontinuity physics. Checking after this cast does not
validate the actual supplied values. Reject non-real inputs before conversion
in both preprocessing and the low-level operator, with equivalent backend
behavior.

### P3: finite factors can overflow the face denominator and silently decouple

`garnet/stencil.py:235` computes the unscaled sum of weighted resistances.
Although the interface law is invariant under a common positive scaling of
its two factors, the implementation can overflow that sum for valid finite
inputs. In a two-cell unit-spacing case with D=1 and removal=0.1, reflective
boundaries and equal factors of 1, the matrix is
`[[1.1,-1],[-1,1.1]]`. Changing both factors to `1e308` passes validation but
produces `[[0.1,0],[0,0.1]]`: interface leakage disappears.

This is a numerical-range edge case; ordinary order-one ADFs did not show this
problem. Normalize each factor pair before forming the resistance and check
that the resulting coefficients are finite. Extend the common-scale invariance
test beyond modest factor scales.

## Verified behavior and remaining limits

The two-sided current formula, opposite-sign face balances, diagonal placement,
CSR assembly and Cartesian algebraic transpose are consistent in the inspected
implementation and ordinary-value independent matrix checks. The dense
two-group forward/adjoint eigenproblem passes, as do analytical heterogeneous
one- and two-group refinement and reference-factor tests. Additional random
positive-factor eigenproblems were checked against dense dominant roots.

Selected regression suite: **137 passed, 3 skipped**, in 26.36 s with
`OPENBLAS_NUM_THREADS=1 PYTHONPATH=.`. Test modules:
`test_cartesian_adf`, `test_adf_slab_reference`, `test_dallosso_adf_reference`,
`test_diffusion_analytic`, `test_fused_kernels`, `test_linalg_krylov`,
`test_diffusion_workflow_api`, and `test_tri_sp3`. `git diff --check` passes.
The Dall'Osso reference-factor example was also run at refinements 4 and 8;
both complete and reproduce their same-grid reference eigenvalue and group
averages within the example's stated tolerances.

The analytical cases verify reference equivalence using factors generated from
the reference answer. They do not demonstrate predictive accuracy of an
independent assembly library. Bernal's geometry remains provisional and the
Dall'Osso interpretation still differs from its reported eigenvalue. The
current documentation acknowledges these limits; neither is an established
published benchmark reproduction. Practical 2-D/3-D homogenization validation,
external-factor conventions and model/transient integration remain unfinished.
The GPU dispatch emulation test replaces the kernel function, so it does not
verify the generated CUDA source; GPU execution remains deferred.

## Resolution of the three findings

All three findings have been fixed:

- The quasi-static loss projection selects its within-group application using
  the eigensolver's `_linear_components` hook, including the ADF transpose for
  the projected adjoint residual. The two-group independent-matrix test now
  checks both exported projected residuals, normalization invariance, and the
  detection of a deliberately distorted adjoint.
- A shared input validator rejects complex/non-real factor arrays before any
  real cast. Both preprocessing and the operator use it. ADFs are real
  quantities; this change prevents accidental complex input from being
  truncated, and does not introduce complex ADF support. Tests check both
  nonzero and zero-imaginary complex arrays and turn warnings into errors.
- Each factor pair is divided by its maximum before casting to the operator
  dtype and evaluating the face resistances. Nonrepresentable factor ratios
  or non-finite/non-positive face coefficients raise `ValueError`. Tests check
  factors scaled by 1e-308 and 1e308 with float32 and float64 operators,
  including forward/transpose application, assembly and currents, plus
  rejection of an unrepresentable factor ratio.

Post-fix regression: **165 passed, 3 skipped** in 35.36 s, covering the audit's
eight verification modules plus `test_quasistatic`. GPU execution remains
deferred. `git diff --check` passes.
